# Mathematical Literature Retrieval Benchmark

An experimental information-retrieval project comparing lexical,
dense, and hybrid retrieval methods on technical mathematical literature.

## Research question

How do lexical, dense, and hybrid retrieval methods compare when
searching highly technical mathematical research literature?

## Planned methods

- BM25 lexical retrieval
- dense embedding retrieval
- hybrid retrieval
- optional reranking

## Evaluation

The project will use manually curated mathematical queries and
relevance judgments, evaluated using standard information-retrieval
metrics such as Recall@k, MRR, and nDCG.

## Current status

Initial arXiv corpus collection.
